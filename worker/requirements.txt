# NOTE: bump this floor to force Modal to rebuild the cached pip layer.
# Modal keys that layer on this file's contents, so a stale floor freezes
# yt-dlp at whatever version resolved on the first build — which is how the
# 2026-08-14 "HTTP 403 Forbidden" outage happened (YouTube applied DRM to
# tv-client formats; the frozen yt-dlp didn't know to skip them).
